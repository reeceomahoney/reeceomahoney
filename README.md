# reeceomahoney

Personal website, built with [Next.js](https://nextjs.org), [Tailwind CSS](https://tailwindcss.com) and MDX.

## Development

```sh
pnpm install
pnpm dev        # start the dev server at http://localhost:3000
pnpm check      # lint and typecheck
pnpm build      # production build
```

Blog posts live in `src/content/*.mdx`.
